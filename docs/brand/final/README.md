# UnBusy brand assets

Generated 2026-10-26 in Higgsfield (GPT Image 2.5, high quality, 2K) from the master logo `unbusy-logo-master.webp`, which is the source of truth for the mark. These are raster PNGs (2048 px on the short side, transparent where noted). A vector master still needs to be traced from `01-icon-light.png` and `02-wordmark-light.png` before print or signage.

## Colors

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#15181D` | The mark and the wordmark on light backgrounds; dark backgrounds |
| Blue | `#0B5CFF` | The dot only, and the blue app icon. Never body text on light backgrounds (contrast fails) |
| Paper | `#FAFAF8` | Light backgrounds; the mark and wordmark on dark |
| Black | `#000000` | One-color print version only |

## Spelling

The wordmark reads **UnBusy**. Use that spelling everywhere the logo appears. In running text, pick one spelling and keep it; the business plan currently says "Unbusy".

## Rules

- Clear space around the logo: at least the height of the dot on every side.
- Minimum size: the mark alone at 16 px; the horizontal lockup at 120 px wide; the stacked lockup at 96 px wide.
- Never recolor the mark except to the versions above. Never stretch, rotate, outline or add effects.
- The dot is always blue on light and dark backgrounds, except the one-color and knockout versions.
