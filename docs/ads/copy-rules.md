# Copy rules

## Voice

Blunt, plain, casual, clean. Short sentences. Every line is a commitment the site already makes (see `claims.md`). The comment at the top of `landing.ts`'s build-assurance block says it best: restate the commitments where the decision happens; promise nothing new.

## Positioning rules (Josh's, non-negotiable)

1. **AI is a product, never the method.** Don't say it at all in these ads; this offer isn't AI.
2. **No invented proof.** No testimonials, logos, ratings, results or "trusted by". An honest ad with no proof beats a fake one.
3. **Not "website makers".** Lead with web apps and dashboards. Websites come last, except in ads that land on `/websites`.
4. **"Cheaper" means no overhead.** No account managers, no hourly billing. Never a price, never "cheap", never "affordable".
5. **Never name a competitor.** Describe the alternatives generically: "a big dev shop", "a freelancer".
6. **No profanity.** Including in video captions and image text.
7. **No location in copy.**

## What makes a SKOX ad work

The buyer has a specific problem. The ad names it in their words, then gives the commitment that removes the risk.

| Buyer problem (their words) | Commitment that answers it | Claim IDs |
|---|---|---|
| "Agencies quoted months and an hourly rate" | A fixed price and a delivery date in writing, before you pay | C03, C12, C13 |
| "We're stuck in spreadsheets / rebuilding the same report" | One clear view of your business; 14-day focused dashboard build | C22, C08 |
| "Our clients email us for everything" | A customer portal, from idea to working software | C21, C01 |
| "Our site is dated and doesn't bring enquiries" | A clear, credible reason to choose you; 7-day focused site build | C09, C21 |
| "Last developer vanished / we got burned" | Work with the two founders building it; you own the code | C14, C07 |
| "I don't know exactly what I need" | Free 30-minute scope call; you keep the plan either way | C04, C19, C26 |

## Three variants, three bets

Per the ad-manager skill (`reference/ad_copy.md`): three variants per ad, each testing one different idea. Three rewordings of the same idea teach nothing. Good bets for SKOX:
- **Speed bet:** the dated build ("14-day focused dashboard build").
- **Certainty bet:** fixed price and date in writing before you pay.
- **People bet:** you work with the two founders, no account manager.

Say which bet each variant is next to it in the campaign file.

## Character limits

| Platform / asset | Limit |
|---|---|
| Google RSA headline | 30 (up to 15 per ad) |
| Google RSA description | 90 (up to 4 per ad) |
| Google display path (×2) | 15 each |
| Google sitelink text | 25; descriptions 35 each (×2) |
| Google callout | 25 |
| Google structured snippet value | 25 |
| Google Demand Gen headline / long headline / description | 40 / 90 / 90 |
| Google video in-stream headline | 15 |
| Meta primary text | 125 shows before "See more" |
| Meta headline | 40 (about 27 show on mobile) |
| Meta description | 30 |

Count characters exactly. Write the count in brackets after every line in a campaign file, e.g. `Fixed price, agreed upfront (27)`. Ampersands, spaces and punctuation count.

## Formatting

- Sentence case or title case is fine. No ALL CAPS words in Google text ads (policy). No more than one exclamation mark per ad, and preferably none.
- No emoji in Google ads. Meta: at most one, and only if it carries meaning.
- Use "&" only where the site does ("Get my price & timeline").
- No phone number in copy; the site doesn't lead with one.
